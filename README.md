# GTO 学院 · 德州扑克策略学习站

**在线访问：<https://grbird0.github.io/gto-academy/>**

一个纯静态、离线可用的无限注德州扑克 GTO 学习网站。不需要联网、不需要安装任何东西。

## 怎么打开

直接双击 `index.html` 即可（已验证在 `file://` 协议下正常工作）。

如果想用本地服务器打开（推荐，行为和线上一致）：

```bash
# 任选其一，在 outputs 目录下执行
npx serve .
python -m http.server 8000
```

想放到线上也很简单——整个目录就是静态资源，丢到 GitHub Pages / Netlify / 任意静态托管即可。

## 目录结构

```
index.html              页面骨架（7 个视图 + 卡牌选择器）
assets/styles.css       全部样式（深色牌桌配色，含移动端适配）
assets/ranges.js        翻前范围数据层：14 张范围表 + 范围表达式解析器
assets/engine.js        计算引擎：牌力评估 / 权益模拟 / 赔率与 EV / 牌面质感
assets/app.js           界面逻辑：范围矩阵 / 计算器 / 测验 / 分析器
```

## 功能一览

| 模块 | 内容 |
| --- | --- |
| 概览 | 学习路径、进度环、**浏览器实时算出的经典对局胜率表**（AA vs KK 等 6 组） |
| 基础理论 | 6 节课程：期望值 / 底池赔率 / 权益实现率 / MDF 与 alpha / 组合数与阻断牌 / GTO 与剥削。前 4 节带可拖动的小实验，第 5 节带交互式阻断牌计算器 |
| 翻前范围 | 14 张 13×13 范围表，覆盖 RFI（5 个位置）、面对开池（5 个场景）、面对 3-Bet（4 个场景）。支持动作视图 / 主频率视图 / 组合数视图，悬停显示每格的动作频率明细 |
| 计算器 | 权益计算器（最多 4 方、手牌或范围、0/3/4/5 张公共牌、蒙特卡洛或 100% 精确枚举）、赔率·MDF、EV·弃牌率 |
| 训练 | 三种题型自动生成：翻前决策（答案取自范围表）、底池赔率、权益估算。带连胜、正确率与错题回顾 |
| 翻后 | 翻牌面分析器（对子结构 / 同花结构 / 连接度 / 高张四个维度 + c-bet 建议），以及范围优势、极化与线性、尺度选择、阻断牌四条主线 |
| 术语表 | 26 个高频术语，支持中英文搜索 |

进度、答题记录会存在浏览器 localStorage 里，不上传任何数据。

## 关于准确性的说明（重要）

**范围表是教学近似值。** 真实 solver 输出带有非常细碎的混合频率（例如某手牌 37% 3-Bet），
并且随开池尺度、是否前注、筹码深度而变化。本站把频率简化为 25% / 50% / 75% 的刻度，
按 6-Max、100bb、无前注整理，目的是解释**范围结构与位置差异**，不能替代 solver 查表。

**胜率是实算的。** 页面里的每一个百分比都来自本站的牌力评估引擎，不是预先写死的数字。

## 验证记录

开发过程中做过的检查：

- **范围数据校验**：14 张表的每一手牌频率之和都 ≤ 100，无非法手牌，各位置范围宽度符合预期
  （UTG 18.2% / HJ 20.8% / CO 26.5% / BTN 43.2% / SB 47.3%）。
- **引擎交叉验证**：快速评估器与「21 种 5 张组合取最大」的朴素参考实现在 40,000 组随机
  7 张手牌上**完全一致（0 处不同）**。
- **精确值比对**：用两套独立实现完整枚举 1,712,304 种公共牌，AA vs KK 均为 **82.637%**；
  22 vs AKs = 50.3%（经典硬币局）、QQ vs AKs = 54.1%，与教科书数值一致。
- **浏览器端**：100 项自动化检查全部通过（渲染、路由、交互、计算、测验、术语搜索、
  4 种视口宽度下的横向溢出与文本裁切检查）。
- **上线后**：对线上地址逐个文件做 SHA-256 比对，7 个文件全部与本地逐字节一致；
  并用无头浏览器打开线上页面确认渲染正常。
